Initialisation du profil

Cette instance ne contient aucun profil candidat. Importez un CV PDF avec une couche texte : l'application créera un CV_MASTER.json fidèle au CV et un PROFILE.json d'évaluation.

{% if not setup.api_key_set %}

Clé API absente : renseignez OPENROUTER_API_KEY dans l'environnement ou la configuration avant l'import.

{% endif %}

Le PDF source et les deux fichiers générés sont conservés dans le répertoire de données persistant, jamais dans l'image Docker. Les préférences qui ne figurent pas dans le CV ne sont pas inventées.
